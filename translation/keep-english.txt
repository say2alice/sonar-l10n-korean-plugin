# 번역하지 않고 영문 그대로 두는 값의 규칙입니다. 형식과 기준은 문서 저장소 번역 지침 §5에 있습니다.
# prefix <키 접두사>, pattern <값 전체와 일치하는 정규식>, key <키> 가운데 하나를 한 줄에 적습니다.

# 인자 이름을 빼면 영문자가 없는 값(인자와 기호만 있는 값, 빈 값)
pattern (\{[A-Za-z0-9_]+\}|[^A-Za-z])*

# 제품명과 상표만으로 된 값
pattern (Sonar|SonarSource|SonarQube|SonarQube for IDE|SonarQube Cloud|SonarQube Server|SonarQube Community Build|SonarLint|SonarCloud)
pattern (GitHub|GitHub Enterprise|GitLab|Bitbucket|Bitbucket Cloud|Bitbucket Server|Bitbucket Data Center|Azure DevOps|Azure DevOps Server|Jenkins|Jira)

# 용어집에서 영문으로 두기로 한 용어만으로 된 값
pattern Code Smells?

# 대문자 약어만으로 된 값(CSV, JSON, URL, PR)
pattern [A-Z]{2,5}

# 기능 이름으로 영문 그대로 두는 값
pattern AI Code Assurance|AI CODE ASSURANCE|AI CodeFix|Remediation Agent

# 보안과 규정 준수 표준의 이름만으로 된 값
pattern (OWASP (Top 10|Mobile Top 10|ASVS|MASVS)( for LLM)?|STIG ASD|PCI DSS|WCAG|EU CRA|CWE Top 25)( [0-9.]+| V[0-9R]+)?
pattern OWASP (Mobile )?Application Security Verification Standard|DISA Security Technical Implementation Guides

# 줄 번호 약식 표기(L12)
key issue.ncloc_x.short

# 지표 이름으로 영문 그대로 두는 값
pattern LCOM4
